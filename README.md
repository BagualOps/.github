# `.github` — organization-level files for BagualOps

This repository is not a tool. It holds the files GitHub reads for the whole organization.

| Path | What it is |
|---|---|
| [`profile/README.md`](profile/README.md) | The text shown on [github.com/BagualOps](https://github.com/BagualOps) |
| [`profile/assets/`](profile/assets) | Images used by that page |
| [`brand/`](brand) | The logo, in the forms we reuse — see [`brand/README.md`](brand/README.md) |

Editing `profile/README.md` on the default branch updates the organization page directly;
there is nothing to deploy.

# Brand

The BagualOps mark: a horse's head and forequarters cut out of a solid **B**, followed by the
wordmark. One ink colour on a warm off-white ground.

| File | Size | Use |
|---|---|---|
| `bagualops-logo-original.jpeg` | 2816 × 1536 | The source image. Everything else is derived from it. |
| `bagualops-logo.png` | 1800 × 443 | Horizontal lockup, trimmed to the artwork with even padding. Use in READMEs, slides and posters. |
| `bagualops-avatar.png` | 1000 × 1000 | The **B** mark alone, centred on a square. Use as the organization avatar and anywhere the full wordmark would be unreadable. |

Colours:

| | Hex | Where |
|---|---|---|
| Ink | `#1D496B` | The letterforms and the solid of the **B** |
| Ground | `#F8F7F5` | The background of every asset above |

The assets keep their off-white ground rather than transparency on purpose: the ink is dark, so
a transparent version would disappear against a dark background, while the ground reads as a
card in both GitHub themes.

Do not recolour the mark, stretch the lockup, or set the wordmark in a substitute typeface —
crop from `bagualops-logo-original.jpeg` instead.

# Brand

The BagualOps mark is a horse's head and forequarters cut out of a solid **B**, followed by the
name set in one weight. It uses a single ink color on a warm off-white ground.

| File | Size | Use |
|---|---|---|
| `bagualops-logo-original.jpeg` | 2816 x 1536 | The source image. Everything else is derived from it. |
| `bagualops-logo.png` | 1800 x 443 | The horizontal lockup, trimmed to the artwork with even padding. Use it in READMEs, slides and posters. |
| `bagualops-avatar.png` | 1000 x 1000 | The **B** alone, centered on a square. Use it as the organization avatar, and anywhere the full name would be too small to read. |

Colors:

| | Hex | Where |
|---|---|---|
| Ink | `#1D496B` | The letterforms and the solid of the **B** |
| Ground | `#F8F7F5` | The background of every file above |

The files keep the off-white ground instead of a transparent one on purpose. The ink is dark, so
a transparent version would disappear against a dark page, while the ground reads as a card in
both GitHub themes.

Do not recolor the mark, stretch the lockup, or set the name in a substitute typeface. Crop a
new asset from `bagualops-logo-original.jpeg` instead.
